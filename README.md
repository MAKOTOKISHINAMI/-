エディタ
使い方ガイド
ベースカラー：色のボタンをおすと、好きな色を選べます。プレートの下地の色になります。
メッセージ追加：文字を入れられます。入れたあと、文字をクリックすると自由に書きかえられます。
写真追加：自分のスマホやパソコンにある写真(JPG・PNG・GIF・WEBP・BMP)をはりつけられます。
スタンプ：用意されているイラストをえらんで、はりつけられます。
描画ツール：ペンで自由に線を書いたり、四角・円・線を書いたりできます。色や太さも変えられます。
写真・文字・スタンプ・図形は、青い枠の角をつかむと大きさを変えられます。上のクルッとしたマークをつかむと回転できます。まん中をドラッグすると移動できます。
いらなくなったら、クリックして選んでから「選択した要素を削除」ボタン、またはキーボードのDeleteキーで消せます。
「前面へ」「背面へ」ボタンで、写真と文字のどちらを上に見せるか変えられます。
表面／裏面のタブで、プレートの表と裏、それぞれ別のデザインを作れます(裏はデザインしなくてもOKです)。
赤い点線は「塗り足し線」です。デザインはこの線まで、はみ出すつもりで作ってください。青い線が、実際にできあがる形の線です。
「3D プレビュー」ボタンで、できあがりのイメージを立体で確認できます。ドラッグすると回転します。
デザインができたら、「確定/購入」ボタンで画像を保存できます。イラストレーターなどで編集したい場合は「SVGで保存」を使ってください。
